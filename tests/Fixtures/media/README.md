These small fixtures are authored for this project; no third-party artwork is included.

- `animated.gif`: 32 × 24, four frames at 0, 80, 270, and 400 ms; total duration 470 ms. Red background, a green partial frame with restore-previous disposal, a blue partial frame with clear-to-background disposal, and a transparent patch. Transparent areas render against white in converted videos.
- `static.gif`: the same first frame, without animation.
- `animated.webm` and `poster.png`: generated by the application's real production worker using Chromium 156.0.8078.4, native ImageDecoder, native VP8 VideoEncoder, and Mediabunny 1.61.5. The video is silent and contains all four original frame timestamps and the full 470 ms cycle.

The native and gifuct-js paths were also exercised in Firefox 157.0. ffprobe independently verified timing and frame count; browser playback, seeking, and sampled frame colors verified disposal and compositing. FFmpeg is only a local inspection tool for this verification, not an application runtime dependency.
