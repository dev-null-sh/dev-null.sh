# Emoji data

`resources/js/lib/emoji-groups.json` includes the 3,944 fully qualified emoji sequences from [Unicode 17 emoji-test.txt](https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt). `emoji-shortcodes.json` preserves the app’s existing text shortcuts. `emoji-picker-shortcodes.json` adds Unicode names, including skin-tone variants, to the picker and reaction validation without changing prose substitution. The same catalog powers the native chat and star pickers and server validation. A user's OS font determines rendering support.
